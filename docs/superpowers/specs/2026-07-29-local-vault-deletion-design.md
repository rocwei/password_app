# App Store 5.1.1(v) 本地密码库删除整改设计

日期：2026-07-29

## 背景与根因

密盾安存没有云端账号、开发者服务器或云同步。首次启动时创建的是设备本地加密密码库，主密码只用于本机验证和派生加密密钥。

当前界面却使用了“创建主账户”“创建账户”“注册”“登录”“登出”等账号系统术语。审核员因此将本地主密码设置流程识别为账号创建，并依据 App Store 审核指南 5.1.1(v) 要求提供账号删除能力。

整改目标是让产品表述与真实架构一致，同时提供一个在 App 内容易找到、可完整演示、能永久删除全部本地数据的操作流程。

## 整改范围

### 1. 用户可见术语

不改变现有数据库结构和核心加密流程，只调整用户可见文案：

| 当前文案 | 整改后文案 |
| --- | --- |
| 创建主账户 | 设置主密码 |
| 创建账户 | 创建本地密码库 |
| 注册失败 | 设置失败 |
| 登录 | 解锁 |
| 登录失败 | 解锁失败 |
| 使用生物识别登录 | 使用生物识别解锁 |
| 登出 | 锁定密码库 |
| 已有账户 / 没有账户 / 点击注册 | 删除，不再显示 |
| 用户未登录 | 密码库尚未解锁 |

内部的 `User` 模型、`registerSingleUser` 等名称暂不重构，避免扩大版本风险。审核判断依据是实际功能和用户界面。

### 2. 删除入口

在“设置 > 数据管理”中增加红色入口：

- 标题：删除本地密码库
- 副标题：永久删除本机保存的密码、分类、OTP 和主密码设置
- 图标：删除图标

入口与“备份与恢复”放在同一区域，审核员无需寻找账号页面即可发现。

### 3. 删除确认流程

删除流程分两步：

1. 输入当前主密码，确认操作人能够解锁当前密码库。
2. 展示不可恢复警告，明确将删除密码条目、分类、OTP、主密码设置、生物识别密钥和主题偏好。按钮文字为“永久删除”。

对话框同时说明：

- 操作无法撤销。
- 开发者没有服务器副本，无法恢复删除的数据。
- 用户已经主动导出到“文件”、网盘、邮件等外部位置的 `.passbackup` 文件不受影响。

主密码错误时不删除任何数据，并显示明确错误。删除进行中禁止重复点击。

## 数据删除设计

删除操作由 `AuthHelper` 提供单一入口，设置页面不直接操作数据库或安全存储。

执行顺序：

1. 使用当前本地用户的盐和哈希值验证主密码。
2. 关闭 SQLite 连接，删除 `password_manager.db`，并将数据库单例连接重置为未初始化状态。
3. 调用安全存储的全量清理，删除 OTP、OTP 索引、生物识别加密密钥和主题偏好。
4. 清除内存中的当前用户、加密密钥和加密器状态。
5. 导航到“设置主密码”页面，并移除之前的全部路由。

SQLite 数据库包含本地用户记录、密码条目和分类。安全存储包含 OTP、生物识别密钥和主题设置。两处都清理后，App 的状态与首次安装一致。

如果删除过程中发生异常：

- 不显示成功提示。
- 保留当前页面并显示失败原因，允许用户重试。
- 数据库删除成功但安全存储清理失败时，仍保留内存会话到当前页面，便于再次触发安全存储清理。

## 页面与文件影响

预计修改：

- `lib/pages/register_page.dart`：改为本地密码库设置文案，移除账号跳转。
- `lib/pages/login_page.dart`：改为解锁文案，移除注册入口。
- `lib/pages/settings_page.dart`：增加删除入口、主密码验证和二次确认；将登出改为锁定。
- `lib/helpers/auth_helper.dart`：增加主密码验证和删除全部本地数据入口。
- `lib/helpers/database_helper.dart`：增加关闭并删除数据库、重置连接的方法。
- 其他包含用户可见“登录/注册”提示的页面：改为“解锁/设置密码库”语义。
- `docs/app_review_notes.md`：补充无服务器账号说明、删除路径和录屏步骤。
- `docs/privacy_policy.html`、`docs/support.html`：补充本地数据删除说明。

不会修改用户当前未提交的无关页面内容，也不会更改加密算法、备份文件格式或 App Store 截图。

## 测试与验收

自动验证：

- 主密码正确时允许执行删除；主密码错误时不触发删除。
- 删除操作会调用数据库删除、安全存储清理和会话清理。
- 任一步骤失败时不会跳转或显示成功。
- 首次设置、解锁和设置页面不再出现“账户、注册、登录、登出”等账号系统文案。
- `flutter analyze`、`flutter test` 和 iOS 无签名 Release 构建通过。

真机验收与审核录屏：

1. 卸载并重新安装 App，打开“密盾安存”。
2. 在“设置主密码”页面创建本地密码库。
3. 新增一个示例密码条目和一个示例 OTP。
4. 进入“设置 > 数据管理 > 删除本地密码库”。
5. 输入主密码并确认“永久删除”。
6. 展示 App 返回“设置主密码”页面。
7. 关闭并重新打开 App，再次展示无旧数据且进入首次设置页面。

录屏必须使用实体设备，避免展示真实密码、真实邮箱、真实账号或私人 OTP。

## App Review 回复口径

回复中说明：

- App 不创建云端账号，也没有开发者服务器。
- 旧版本中的“创建账户/登录”实际是建立和解锁设备本地加密密码库，术语已更正。
- 新版本提供“设置 > 数据管理 > 删除本地密码库”，会立即删除全部本地密码、分类、OTP、主密码验证记录和生物识别密钥。
- 附件录屏完整展示创建本地密码库、进入删除入口、确认删除以及回到首次设置页面。
