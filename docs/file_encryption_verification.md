## 已批准契约

1. 仅 iOS。入口直接显示在“设置 > 数据管理 > 文件加密”，位于备份下方。进入时进行二次验证：可使用已启用的生物识别，或独立使用当前主密码；未启用生物识别时使用当前主密码。失败或取消本身不放行，之后输入正确的当前主密码可以进入，不属于绕过验证。
2. 从“照片”或“文件”一次选择并处理一个 MP4、MOV、M4V 视频。导入前警告原件保留，不支持其他文件格式或批量导入；内部编码仍需设备支持。
3. Apple CryptoKit AES-GCM 按 1 MiB（1,048,576 字节）分块加密；使用随机生成、仅限本机的专用 Keychain 密钥，不从主密码派生。修改主密码不影响已有视频。
4. 视频密文与加密元数据存于 ApplicationSupport，排除系统备份；密钥不进行云同步或跨设备迁移。不生成缩略图，不提供视频导出、分享、重命名或备份迁移。
5. 不运营云服务器，不上传视频或元数据；选择 iCloud 照片、iCloud Drive 或其他提供方的源文件时，系统或提供方可能先下载选定源文件。原件及其云端副本不受应用加密或删除操作管理。
6. `.passbackup` 不包含视频、视频元数据或专用密钥；恢复密码库备份不删除或覆盖本机已有视频。
7. 整个视频完整解密并通过认证后才向原生 AVPlayer 提供临时文件。临时明文使用完全文件保护（NSFileProtectionComplete）；关闭、后台、取消均清理，进程被终止后由下次启动清理。不得承诺零明文或安全擦除。
8. 删除本地密码库包括加密视频、加密元数据、视频临时文件及专用密钥。视频清理失败须在删除对话框中显示失败并允许重试，不报告成功；流程停在密码数据库删除之前，不进入新密码库创建流程，不把旧视频密钥复用于新密码库。已删除的视频文件不能恢复，不能宣称所有视频删除操作已回滚。重启重试启动时的临时文件清理，不自动续删整个密码库；需要时由用户重新进入删除对话框重试。无需新增持久化的整库删除授权标记。

## Required Reason API 隐私清单

以下为已加入应用代码的声明依据，不是照片或 Face ID 的用户授权弹窗，也不是出口合规认定。

| 类别 | 原因码 | 本功能用途与约束 |
| --- | --- | --- |
| `NSPrivacyAccessedAPICategoryDiskSpace` | `E174.1` | 通过 `systemFreeSize` 等在导入、解密写文件前检查空间，不足时阻止操作并显示用户可见提示；空间及派生信息不外发。 |
| `NSPrivacyAccessedAPICategoryFileTimestamp` | `C617.1` | `fstat` 等读取应用容器内文件时间戳、大小或其他元数据。 |
| `NSPrivacyAccessedAPICategoryFileTimestamp` | `3B52.1` | `fstat` 等读取用户通过文件选择器明确授权的外部文件元数据；例如导入前后校验大小及修改时间。 |

Apple 将 `fstat` 列入 FileTimestamp 类别；不能因只使用文件大小就忽略声明。`E174.1` 要求基于空间产生用户能观察到的行为差异，不是任意采集磁盘信息的许可。依据：[Apple 官方 API 类别及原因码](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype)。

实际清单按调用范围选择原因，应用代码使用的 API 由应用自身清单声明，并已检查最终包内资源；依赖的清单不能代替应用自身声明。依据：[Apple Required Reason API 声明要求](https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api)。打包通过不代表 App Store 已接受提交。

- 每项保留状态“未执行 / 通过 / 失败 / 阻塞”、实际结果及证据；阻塞和未执行不能记为通过，模拟器结果另列。

- 对至少 2 GB 的性能不预先承诺耗时或内存数值；按设备实测记录准备、导入、播放与后台处理，失败需修复后复验。
- 日志、截图与样本摘要不得泄露真实密码、密钥、私人视频内容或敏感文件名。不以普通文件删除宣称安全擦除，也不以启动清理宣称进程终止时立即清除明文。
